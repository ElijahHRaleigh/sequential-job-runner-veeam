# sequential-job-runner-veeam

This script should be relatively easy for any backup admin to deploy. Instead of running backup jobs manually or setting reminders, you can just set this and forget it. 

I recommend enabling email alerts for jobs that are successful and either creating a powershell job for this or just running this in task scheduler (although me personally, powershell jobs are much better)

Let me know what you think! If you have any ideas or want some improvements, feel free to reach out.
